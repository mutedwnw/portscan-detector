# Port Scan Detector

[English version](README.md)

Учебный CLI на Python для поиска признаков TCP-сканирования в CSV, PCAP и
PCAPNG. Выводит таблицу и сохраняет JSON/CSV. Проект предназначен для обучения
и анализа трафика собственной лаборатории.

Алерты связаны с MITRE ATT&CK
[T1046 — Network Service Discovery](https://attack.mitre.org/techniques/T1046/).
Срабатывание — повод для анализа, а не доказательство атаки.

## Установка

Нужен Python 3.11 или новее. В папке проекта на macOS/Linux:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
```

Если `python3` старее 3.11, используй установленную новую версию, например
`python3.11 -m venv .venv`. Установка `-e .` добавляет команду
`portscan-detector`. Проверенные версии основных зависимостей закреплены в
`requirements.txt`. Для pcap дополнительно установи:

```bash
python -m pip install scapy==2.8.0
```

Альтернатива: `python -m pip install -e '.[pcap,test]'` устанавливает проект и
обе группы необязательных зависимостей с диапазонами из `pyproject.toml`.

## Запуск

Из папки проекта с активированным окружением:

```bash
portscan-detector --input samples/events.csv --config config.yaml
portscan-detector --input samples/events.csv --config config.yaml --output reports/alerts
```

Создаются сразу два отчёта: `reports/alerts.json` и `reports/alerts.csv`.
Расширение `.json` или `.csv` в `--output` обозначает общее имя для обоих
форматов. Другие точки сохраняются: `alerts.run1` создаёт `alerts.run1.json`
и `alerts.run1.csv`. Существующие отчёты заменяются. Перезапись входного файла
или конфигурации запрещена, в том числе через символические и жёсткие ссылки.

Без установки проекта также работает прежняя команда:

```bash
PYTHONPATH=src python -m detector.cli --input samples/events.csv --config config.yaml
```

Для `.pcap` и `.pcapng` используется Scapy, для остальных расширений — CSV.
Пути отсчитываются от текущей папки. Конфигурация по умолчанию — `config.yaml`.
Код завершения `0` означает успешный анализ, даже если есть алерты; `2` — ошибку
входных данных, конфигурации или записи отчёта.

## Правила и скользящее окно

Попыткой подключения считается начальный SYN без ACK. Ответы сервера и пакеты
установленного соединения не считаются новыми попытками.

- **Вертикальное сканирование:** один источник, много уникальных портов одного назначения.
- **Горизонтальное сканирование:** один источник, один порт на множестве адресов.
- **SYN без ACK:** много SYN от одного источника, для которых не найден подходящий
  ACK за `syn_ack_timeout_seconds` секунд; по умолчанию — 5 секунд.

Перед анализом события сортируются. В момент `t` окно включает события от
`t - window_seconds` до `t`, обе границы включительно. Старые события удаляются
из всех групп, включая неактивные. Счётчики уникальных значений обновляются при
добавлении и удалении событий. Алерт появляется при достижении порога; новое
срабатывание возможно после снижения счётчика ниже порога.

ACK сопоставляется по IP источника, IP назначения, порту назначения и, для pcap,
порту источника. ACK ровно на границе таймаута принимается. События с одинаковой
меткой времени считаются одновременными. В CSV нет порта источника, поэтому
сопоставление приблизительное. ACK после таймаута не отменяет истёкшую попытку.

Таймауты считаются по времени в файле. Последнее TCP-событие задаёт конец
наблюдения. Если срок ожидания SYN выходит за него, такой SYN не считается
подтверждённым таймаутом. Пустой хвост захвата без TCP-событий не увеличивает
время наблюдения для детектора.

Правила могут пересекаться. `Count` — значение в момент достижения порога:
уникальные порты, уникальные адреса или SYN-пакеты, включая повторные передачи.
Это не размер всего сканирования. `first_seen` и `last_seen` относятся к исходным
событиям в сработавшем окне, а не к моменту проверки таймаута. Время указано в
UTC; каждый алерт содержит `mitre: T1046`.

## Настройки

```yaml
window_seconds: 60
syn_ack_timeout_seconds: 5

thresholds:
  vertical_unique_ports: 20
  horizontal_unique_hosts: 20
  syn_without_ack: 20
```

Все значения — положительные целые числа. Пропущенные настройки получают эти
значения по умолчанию; неизвестные ключи отклоняются, чтобы выявить опечатки.
Таймаут ACK нужно выбирать с учётом задержек сети. По этому правилу нельзя
достоверно определить конкретный режим Nmap.

## Формат CSV

Обязательны заголовок и пять столбцов:

```csv
timestamp,src_ip,dst_ip,dst_port,flags
2026-01-01T12:00:00Z,192.0.2.1,198.51.100.1,443,SYN
2026-01-01T12:00:01Z,198.51.100.1,192.0.2.1,50000,"SYN,ACK"
2026-01-01T12:00:02Z,192.0.2.1,198.51.100.1,443,ACK
```

Время должно содержать часовой пояс; оно переводится в UTC. IPv4/IPv6-адреса
проверяются и приводятся к единой форме. Флаги: `NS`, `CWR`, `ECE`, `URG`, `ACK`,
`PSH`, `RST`, `SYN`, `FIN` или отдельное `NONE`. Разделитель флагов — пробел или
запятая. Поле с запятой обязательно заключать в кавычки.

Строки с неверными значениями, лишними или недостающими полями пропускаются с
предупреждением. Неполный заголовок и дубли столбцов отклоняются. Повреждение
структуры CSV, например незакрытая кавычка или превышение лимита размера поля,
останавливает анализ с понятной ошибкой: продолжение потребовало бы угадывать
границы записей. Кодировка — UTF-8, допускается BOM.

## Учебные данные

```bash
python samples/generate_samples.py
portscan-detector --input samples/events.csv --config config.yaml
```

Генератор создаёт обычные подключения с ACK и три сценария сканирования.
Дополнительное позднее TCP-событие позволяет дождаться таймаутов последних SYN.
С настройками по умолчанию ожидаются пять алертов:

| Правило | Источник | Цель | Count | MITRE |
| --- | --- | --- | --- | --- |
| vertical_scan | 203.0.113.10 | 198.51.100.10 | 20 | T1046 |
| syn_without_ack | 203.0.113.10 | несколько назначений или портов | 20 | T1046 |
| horizontal_scan | 203.0.113.20 | порт назначения 445 | 20 | T1046 |
| syn_without_ack | 203.0.113.20 | несколько назначений или портов | 20 | T1046 |
| syn_without_ack | 203.0.113.30 | несколько назначений или портов | 20 | T1046 |

В консоли также отображаются столбцы времени; здесь они опущены для компактности.

## Тесты

```bash
python -m pytest -q
```

Проверяются обычные и параллельные соединения, оба направления трафика,
таймауты ACK, неполное наблюдение, повторные волны, границы окна, повреждённые CSV,
IPv6, настройки, пути отчётов и pcap/pcapng. Без Scapy проверки pcap пропускаются.
GitHub Actions настроен на тесты и пример CLI для Python 3.11–3.15.

## Ограничения

- Медленный скан может оставаться ниже порога в каждом окне.
- Интенсивные легитимные попытки подключения тоже могут достичь порога.
- Потери пакетов, поздние ACK, закрытые/фильтруемые порты и повторные передачи
  влияют на SYN-эвристику; повторный SYN считается отдельным событием.
- В CSV нет порта источника. В pcap не проверяются TCP sequence/acknowledgement
  numbers; повторное использование потока также может дать неоднозначность.
- Базовые IPv6 TCP-пакеты и нормализация адресов проверены. Сборка IP-фрагментов,
  интерпретация туннелей и другие сложные случаи не реализованы.
- Файл и отсортированные события находятся в памяти. Счётчики окна ускорены,
  но детектор остаётся инструментом для анализа готовых файлов.
- Алерты содержат снимки пересечения порога, а не полные эпизоды сканирования.
- Библиотека чтения не всегда отличает повреждённый захват от конца файла;
  инструмент не проверяет криминалистическую целостность pcap.

## Что улучшить

- Потоковое чтение упорядоченных логов для экономии памяти.
- Учёт повторных передач и TCP sequence numbers.
- Размеченные лабораторные захваты и более широкие проверки IPv6/фрагментации.
- Оценка порогов на больших наборах обычного трафика и сканирования.

## Структура

Код находится в `src/detector/`: `parser.py` читает файлы, `rules.py` ищет
события, `report.py` формирует отчёты, `cli.py` связывает компоненты и настройки.
`tests/` содержит тесты, `samples/` — генератор, CSV и инструкцию лаборатории.
`config.yaml` задаёт пороги, `pyproject.toml` описывает установку и команду CLI,
`requirements.txt` закрепляет версии. `.github/workflows/tests.yml` запускает CI.
